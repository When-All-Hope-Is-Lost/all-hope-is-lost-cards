# All Hope Is Lost: offline card format (v1.0)

## Why this exists
One set of plain files has to feed two kinds of readers: an assistant app's offline crisis feature and a **free standalone app** (a static HTML/PWA now, an APK later). Both must work **fully offline**, with **no server and no account**, and must be easy to mirror (zip file, GitHub Releases, Internet Archive). Markdown with YAML front matter is readable without any app, diff-friendly, and simple to parse on any platform.

## 1. File layout
```
cards/
  FORMAT.md        ← this contract
  index.json       ← machine index (generated by tools/build_index.py)
  index.md         ← human index (generated)
  QA.md            ← per-card review checklist and log
  tools/build_index.py
  <category>/<id>.md   ← one card per file
```
- File name = `id` + `.md`. IDs are lowercase kebab-case, prefixed by category (e.g., `fa-severe-bleeding`). **IDs never change once published.** A replaced card gets `status: retired` instead of being deleted.
- Encoding UTF-8, LF line endings. No images in v1 (text-only keeps the bundle small and avoids image-license problems).
- Categories (folders): `crisis`, `first-aid`, `water`, `food`, `shelter`, `utilities`, `medication`, `weather`, `security`, `sanitation`, `wildlife`, `animals`, `comms`, `hazmat`, `fire`, `vehicle`, `structure`.

## 2. Front matter (YAML), required fields
```yaml
id: fa-severe-bleeding                # string, == filename
title: Severe bleeding                # plain language
category: first-aid                   # one of the folders
tags: [bleeding, tourniquet, trauma]  # lowercase search terms and synonyms
urgency: call-911-now                 # call-911-now | urgent | soon | info
version: 1.0.0                        # semver; bump minor for wording, major for changed instructions
last_reviewed: 2026-10-16             # ISO date of the last self- or expert review
sources:                              # ≥1; every fact in the card must trace to one of these
  - title: "ATP 4-02.11 Casualty Response, TCCC, and First Aid (23 Mar 2026), ch. 4"
    url: https://armypubs.army.mil/...
    checked_date: 2026-10-16
    license: "Public domain (US Government work); Approved for public release"
card_license: CC BY-SA 4.0            # license of OUR card text
review_status: self-reviewed          # draft | self-reviewed | expert-reviewed | retired
region: US                            # US | US-MO | etc. (state-specific rules)
```
Optional: `further_reading` (list of {title, url}, for copyrighted sources we link but never copy), `related` (list of card ids), `verify` (list of strings naming unconfirmed items; the app shows a "Some details need checking" badge if non-empty), `crisis_link: true` (adds the crisis bar to the top).

## 3. Body (Markdown), fixed section order and headings
```
## Do this now
One line. The single most important action.

## Steps
1. … (numbered, imperative, short)

## If / then
- **If** <observable condition> **then** <action>

## Don't
- …

## Get help now
- Escalation signs and who to call (911, 988, Poison Help 1-800-222-1222, etc.)

## Source & license
Plain-text attribution line(s), required disclaimers, and the card license.
```
Readers must render these six headings in this order. Unknown extra sections must be ignored, not errors. Body text is plain CommonMark: no HTML, no scripts, no remote embeds.

## 4. Offline and mirroring contract
1. **Self-contained:** a card must be fully usable with no network. Links (`url`, phone numbers) are *extras*. Every instruction needed to act is in the text.
2. **No model required:** apps display cards directly (topic browse + keyword/tag search over `index.json`). An optional on-device model may only summarize a matched card and must show the card itself.
3. **No accounts, no telemetry, no server.** The PWA ships the cards in its cache. The APK bundles them.
4. **Mirrorable:** the whole `cards/` folder can be zipped and published (GitHub Releases, Internet Archive). `index.json` includes a `generated` date and a per-card `sha256`, so mirrors can be checked for tampering.
5. **Phone numbers** are written in full (e.g., `1-800-222-1222`, `988`). Apps may turn them into `tel:`/`sms:` links.
6. **Crisis cards** (`category: crisis`) are always bundled in every build, including slim builds.

## 5. Content and license rules
- **Allowed sources to write from:** US federal public-domain works (ATP 3-50.21, ATP 4-02.11 / TC 4-02.1, FEMA / Ready.gov / CERT, CDC, NWS, USDA / APHIS, HUD, SAMHSA, HRSA), Missouri state agencies (MDC, DSS, PSC: summarized and linked; check reuse terms), and Wikipedia (CC BY-SA 4.0; attribute the article and revision).
- **Copyrighted sources** (MU Extension, NCHFP, American Red Cross, AHA, ASPCA, wikiHow, other emergency-card apps): `further_reading` links only. **Never copy their text.**
- **Other emergency-card apps:** only the general idea of short action cards is shared. No text or wording is taken from them.
- **CDC material:** credit CDC, include a non-endorsement disclaimer, don't change its substantive meaning, and note it's available free at cdc.gov (CDC "Use of Agency Materials").
- **Ready.gov:** no logos, no implied endorsement.
- **Card license:** our text is **CC BY-SA 4.0** (compatible with Wikipedia excerpts). Public-domain facts stay public domain.
- **Never fabricate numbers.** Every number traces to a listed source. Uncertain items go in `verify`.
- **Safety:** defensive and safety content only. **Never instructions for harming people or animals.** Crisis cards put the crisis lines first, don't lecture, and always offer survival help (food, shelter, 211).
- Medical cards say "get trained" where the source says training is needed, and are flagged for expert review before public release.

## 6. Review workflow
`draft` → (self-review against sources, logged in QA.md) → `self-reviewed` → (qualified medical / crisis-line / legal reviewer) → `expert-reviewed`. **Public release requires expert review for `first-aid`, `crisis`, and `medication` cards**.
